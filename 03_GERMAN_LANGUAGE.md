## AI-POWERED GERMAN LEARNING WORKFLOW (Daily)

### Morning Study (45-60 min of German days)
```
1. Open Nicos Weg lesson (10 min video + exercises)
2. Note new vocabulary → paste into ChatGPT:
   "Generate Anki CSV for these German words: [list]
    Format: German;English;Example sentence;Gender"
3. Import CSV into Anki
4. Do 2-3 grammar exercises from DW
```

### Commute Audio (passive, earbuds)
```
Download offline before leaving home:
- A1-A2: Nicos Weg audio lessons
- B1: Easy German podcast episodes
- B2: DW Langsam Gesprochene Nachrichten
Just listen. Don't stress about understanding everything.
```

### Evening German (45-60 min on German days)
```
1. Anki review (15 min — spaced repetition, never skip)
2. Write 5-10 sentences about your day in German
3. Paste into ChatGPT/Claude:
   "Correct my German text and explain each mistake:
    [your text]"
4. Study the corrections
```

### Weekend Speaking (1-1.5 hrs)
```
Option A (Free): ChatGPT Voice Mode
  "Let's have a conversation in German at [A2/B1/B2] level.
   Topic: [daily life/work/technology].
   Correct my grammar at the end of each exchange."

Option B (Paid, better): italki tutor (~₹500-1000/session)
  - Real human interaction
  - Cultural nuances
  - Accountability
```
