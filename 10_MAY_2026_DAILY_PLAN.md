## 🧠 HOW TO USE AI CORRECTLY (The "AI Detox" Protocol)

### ✅ AI IS ALLOWED FOR:
- "Explain what a pointer is in C. Use a diagram."
- "Why does `int *p = &x; *p = 5;` change x?"
- "What is the difference between stack and heap memory?"
- "Quiz me on C data types."
- "Correct my German sentences: Ich komme aus Indien."
- "What does this GCC error mean: `segmentation fault (core dumped)`?"

### ❌ AI IS BANNED FOR:
- "Write a C program that sorts an array" ← YOU must write it
- "Fix this code for me" ← YOU must debug it with `gcc -Wall` and `gdb`
- "Generate a complete linked list implementation" ← DO IT YOURSELF
- Any form of copy-pasting AI-generated code into your files

### The Rule:
> **AI explains concepts. YOU write code. Testing is done with `gcc -Wall` and `gdb`, NOT by asking AI to fix errors.**
