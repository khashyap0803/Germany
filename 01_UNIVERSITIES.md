## ⚙️ WHAT COUNTS AS "CONTROL ENGINEERING" CREDITS (general rule)

German assessors (uni-assist, admission committees) read the **module description**, not the course title. A course counts as control engineering (*Regelungstechnik*) if most of it covers **feedback control**:
transfer functions & block diagrams → **feedback loops** → **stability** (Routh–Hurwitz, root locus, Bode, Nyquist) → steady-state error → **controller design (P/PI/PID, lead–lag compensators)** → state-space (controllability, observability, state feedback).

| Usually counts ✅ | Sometimes / partly ⚠️ | Usually does NOT count ❌ |
|:---|:---|:---|
| Control Systems / Control Engineering / Linear Control Systems / Feedback Control | Industrial Automation, PLC & SCADA (*Automatisierungstechnik* — some programs list it separately) | **Signals & Systems** (counted as signal processing / systems theory) |
| Modern Control Theory / State-Space Control / Advanced Control | Process Control & Instrumentation, Measurement and Control (*Mess- und Regelungstechnik*) — only the control part | Digital Signal Processing |
| Digital (Discrete-time) Control Systems | Control of Electric Drives, Power Electronics control | Network Analysis / Circuit Theory |
| Nonlinear, Optimal, Robust, Adaptive Control (electives) | Robotics (mostly kinematics; counts only if it includes robot control) | Linear ICs / op-amps (even PID op-amp circuits) |
| Control Systems **Lab** (the lab's own credits count) | Mechatronics (only the control part) | Communication systems, Microcontrollers, "Systems Engineering" |

**Signals & Systems — the honest answer:** no, normally it does **not** count as control. It teaches the maths control uses (Laplace, Fourier, Z-transform, LTI systems, convolution) but not feedback or controller design.
- **Exception:** a few programs ask for a *combined* block such as "**Systems Theory and Control** (*Systemtheorie und Regelungstechnik*) — X CP". There, Signals & Systems can count towards the total.
- Read each program's exact wording.

**Credit conversion:** most assessors scale proportionally. A 4-year Indian degree (≈160 credits) is treated as 240 ECTS, so **ECTS ≈ Indian credits × 1.5**: 3 → 4.5, 4 → 6. Some use workload instead (1 ECTS = 25–30 hours).
